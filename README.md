<!-- S01 Mini Activity - SWOT Analysis -->

Strengths

- JWT authentication with bcrypt for secure login.
- Clear Model‑Controller‑Routes architecture with proper HTTP status codes.
- Complete CRUD flow for products, cart, and orders.

Weaknesses

- No automated tests implemented yet.
- Limited frontend UI/UX polish and responsiveness.
- Input validation/sanitization layer not fully enforced.

Opportunities

- Integrate real payment gateways (Stripe, PayPal, PayMongo).
- Add advanced features: product ratings, reviews, wishlists, coupons, shipment tracking.
- Improve architecture robustness and deploy with CI/CD to cloud hosting.

Threats

- Invalid data and lack of validation could cause system errors.
- Security risks such as DDoS, unauthorized access, and data breaches.
- Scaling issues and free‑tier database limitations as user base grows.
